# Gallery screenshots

Uploaded by hand through the Mod Hub. These files are not part of the mod or the Python wheel.

All four slots are required: PNG, exactly 1920x1080, taken in the game. Keep the `NN-` prefix; the rest of the name is free.

| Slot | Example file | Subject | Caption |
| --- | --- | --- | --- |
| 01 | `01-mod-list.png` | The game's mod list with TF3 Companion Bridge enabled | The bridge is a cosmetic, read-only script mod. |
| 02 | `02-company-findings.png` | An AI assistant answering a company question with findings and numbers | Findings with the numbers behind them. |
| 03 | `03-report.png` | A report or the exported spreadsheet | Reports built from your own snapshots. |
| 04 | `04-line-problem.png` | A loss-making line in the game beside its finding | Spot the line that loses money, then fix it yourself. |

Check with `uv run python scripts/check_listing.py`, which names any missing or invalid slot.
