# Snapshot data — schema v1

Generated by the `tf3_companion_bridge` mod in `<userdata>/towns_industries/tf3c_snap_<gameTime>.lua`, the only output sink, using `app.saveUserdata`. The game time in the filename is zero-padded to 15 digits. Refresh requests use `towns_industries/tf3c_request.lua`; the CLI is `tf3c` and the log prefix is `[tf3c]`. Times (`gameTime`, `purchaseTime`) use the game's internal unit; `meta.yearDuration` is the duration of one year in that unit (`api.util.getDefaultYearDuration()`). Money uses game units. IDs identify game entities (stable while the entity exists). Finding categories are `finance|lines|vehicles|industries|data`.

## When it is generated

- On loading a save (the first frame with the mod active).
- Every 1/12 of a game year.
- When the companion requests it (`refresh`, or `tf3c refresh`, writes `towns_industries/tf3c_request.lua` with an `id`; the mod checks every 60 frames).
